COLE FIT - EXERCISE GUIDES EDITION

Upload index.html, guides.js, builder.js, plus.js, coach.js, sw.js, manifest.webmanifest, and icon files to the ROOT of your GitHub Pages repository.
Keep any existing cloud-config.js only if you intentionally still use cloud syncing; this local-first package does not require it.

New Guides tab: search exercise names, read beginner-friendly instructions, tap Find instruction videos (opens YouTube exercise-search results, not a curated or embedded single video).
How-to buttons also appear on workout cards, exercise library results, and the custom builder.

Your workout history is saved in browser storage; export existing history before replacing files. Clear cached website files only after backing up.

Videos require internet access and are provided by YouTube. The website does not host or upload videos.
